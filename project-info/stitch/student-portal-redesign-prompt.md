# Google Stitch Prompt: Student Dashboard & Portal Redesign

## Goal
Redesign the entire Student Portal experience of the "EduFlow" Institute Management System (IMS). The objective is to unify the post-login interface with the modern, airy, and professional brand identity established on the Public Landing Page.

## Visual Identity (Unified with EduFlow Landing Page)
- **Primary Colors**:
  - Main Accent: `#2A6DF4` (Bright Indigo-Blue)
  - Deep Tone: `#1A3D8A` (Deep Blue)
  - Surfaces: `#FFFFFF` (Pure White), `#F7F9FF` (Soft Light Blue/Gray)
  - Borders: `#E2E8F8` (Thin, elegant lines)
- **Typography**: Clean, Modern Sans-Serif (e.g., Inter, Outfit). Use `semi-bold` for emphasis instead of heavy `black`. Avoid excessive `italic uppercase`.
- **Feel**: High whitespace, breathable layouts, premium SaaS-dashboard aesthetics.

## Key Screens to Redesign

### 1. Student Dashboard Home (The Hub)
- **Hero Banner**: A welcoming header with a personalized message and "Pulse" stats (Attendance %, Next Class).
- **Navigation Grid**: Large clickable cards for "Timetable", "Assignments", "Attendance", and "Syllabus".
- **Dynamic Schedule**: A vertical timeline of today's classes with Subject, Time, Room, and Instructor.
- **Announcements**: A "Intelligence Feed" card show-casing recent institution notices.

### 2. My Finance (Fee & Payments)
- **Summary Header**: Four distinct cards showing Total Due, Amount Paid, Remaining Balance, and Invoices.
- **Transaction Ledger**: A clean, interactive table documenting fee heads, due dates, and payment status (Paid, Partial, Unpaid).
- **Audit Feed**: A history of recent payments with "Download Receipt" icons.



### 6. Student Profile
- **Information Architecture**: Split between Personal Profile (Avatar, Bio) and Academic Context (Program, Enrollment ID).

## Design Instructions for Stitch
- **Consistency**: Use the same button styles and input designs as the Auth module.
- **Hierarchy**: Use `#2A6DF4` for primary actions and status indicators.
- **Illustrations**: Incorporate subtle, thin-line SVG icons (Lucide/Phospor style) that match the Landing Page.
- **Interactive Elements**: All cards should have a subtle hover-lift effect. Progress bars should have soft color transitions.
- **Dark Mode**: While the default is white/airy, ensure the color tokens allow for a premium dark-mode transition in the future.
