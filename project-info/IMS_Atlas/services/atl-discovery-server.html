Discovery Server (`atl-discovery-server`)

Service registry based on Netflix Eureka. Enables dynamic service discovery and client-side load balancing.

Context Map

graph LR ServiceA[Microservice A] -->|Registers| Discovery[Discovery Server] ServiceB[Microservice B] -->|Registers| Discovery Gateway -->|Queries| Discovery

Responsibilities

  • Maintain a registry of active service instances.
  • perform health checks to evict unavailable instances.
  • Provide service locations to the Gateway and other internal clients.
