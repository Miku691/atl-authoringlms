Web UI (`atl-web-ui`)

The single-page application (SPA) built with React and TypeScript.

Context Map

graph TB User[User] --> WebUI[Web UI] WebUI --> Gateway[API Gateway]

Responsibilities

  • Provide user interface for all personas (Admin, Staff, Student, etc.).
  • Handle client-side routing via React Router.
  • Manage user session and JWT storage via Redux Persist.
  • Dynamic Sidebar configuration based on roles.

Internal Architecture

The Web UI follows a component-based architecture using React, Redux for state management, and TailwindCSS for styling.

classDiagram class App { +Router +ReduxProvider +Toaster } class Store { +AuthSlice +ThemeSlice } class Layouts { +AdminLayout +AuthLayout +StudentLayout } class Pages { +Dashboard +UserManagement +Academics } class Components { +Sidebar +Navbar +DataGrid +Forms } App --> Store App --> Layouts Layouts --> Components Layouts --> Pages Pages --> Components

State Management Flow

flowchart TD Action[User Action] --> Dispatch[Dispatch Action] Dispatch --> Thunk[Redux Thunk / API Call] Thunk -->|Request| API[Backend API] API -->|Response| Thunk Thunk --> Reducer[Redux Reducer] Reducer --> Store[Global Store] Store -->|Updates| Components[React Components]

Directory Structure

  • src/
    • components/ - Reusable UI components (Buttons, Inputs, Sidebar)
    • layouts/ - Page wrappers (AdminLayout, AuthLayout)
    • pages/ - Route-specific page components
    • store/ - Redux configuration and slices
    • config/ - Static configurations (SidebarConfig)
    • utils/ - Helper functions and Axios interceptors
