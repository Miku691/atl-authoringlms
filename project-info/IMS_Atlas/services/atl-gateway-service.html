Gateway Service (`atl-gateway-service`)

The centralized entry point for all API traffic, routing requests to appropriate microservices.

Context Map

graph LR Client[Client] --> Gateway[Gateway Service] Gateway --> Auth[Auth Service] Gateway --> Academic[Academic Service] Gateway --> Student[Student Service] Gateway --> Instructor[Instructor Service] Gateway --> Staff[Staff Service] Gateway -.-> Discovery[Discovery Service]

Responsibilities

  • Routing: Directs incoming API requests to the correct microservice based on the path.
  • Security: Enforces security headers and initial CORS policies.
  • Authentication: Validates JWT tokens for protected routes (via filter).
  • Load Balancing: Distributes traffic across service instances (client-side load balancing via Discovery).

Key Configurations

  • Routes are configured in `application.yml` / `properties`.
  • Uses Global Error Attributes for consistent error responses.
  • Integrates with Zipkin/Sleuth for distributed tracing (if enabled).
