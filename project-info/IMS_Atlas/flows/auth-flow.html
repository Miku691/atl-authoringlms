Authentication Flow

Visualizing how users authenticate and obtain access tokens.

Sequence Diagram

sequenceDiagram actor User participant WebUI as Web UI participant Gateway participant Auth as Auth Service participant DB as User DB User->>WebUI: Enters Credentials WebUI->>Gateway: POST /auth/login Gateway->>Auth: Forward Request Auth->>DB: Validate Credentials DB-->>Auth: User Valid Auth-->>Auth: Generate JWT Auth-->>Gateway: Return Token Gateway-->>WebUI: Return Token WebUI-->>User: Login Success (Store Token)

Process Steps

  1. User submits username/password via the Web UI login form.
  2. Request is sent to the API Gateway.
  3. Gateway routes the request to the `atl-auth-service`.
  4. Auth Service validates credentials against the database.
  5. If valid, a JWT (JSON Web Token) is generated containing user roles and tenant ID.
  6. The token is returned to the client and stored for subsequent requests.
