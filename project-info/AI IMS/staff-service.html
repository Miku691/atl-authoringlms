Mapping & Implementation Notes

  • staff.user_id → linked to auth.users (parents, operators, admins all login via auth-service).
  • staff_roles enables institution-level RBAC separate from auth.roles.
  • Parent accounts are stored in staff-service with relation_type = 'parent'.
  • File URLs (documents) should be stored in S3/MinIO.
  • Index contact_number and tenant_id for fast lookup.
  • Use soft-delete for staff leaving the institution.
