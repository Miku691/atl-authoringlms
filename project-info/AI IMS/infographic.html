🎓 Educational ERP – Microservices Architecture

AI-Integrated • Multi-Tenant • Cloud-Native • Microservice-Based SaaS

🧑‍💻 Client (Web & Mobile)
React.js • Mobile App (Future)
⬇
🌐 gateway-service
Request routing • Rate limiting • Authentication forwarding • Logging
⬇
🔐 auth-service
User login • JWT issuing • OAuth2 • Role/Permission mapping • Tenant (school_id) resolution

🏛️ Core Domain Microservices

🎓 student-service

Handles student profiles, enrollment history, guardians, ID cards, academic lifecycle & status.

👩‍🏫 instructor-service

Teacher profiles, qualifications, subject specialization, workload, availability & schedules.

👥 staff-service

Non-teaching staff, admin staff, operator roles, parents, and management-level employee profiles.

📚 academic-service

Courses, classes, subjects, syllabus structures, chapters, batches, timetable rules & academic years.

💰 finance-service

Fee structures, invoicing, fee collection, payment gateway integration, staff payroll, expenses & ledgers.

🛠️ admin-service

Super-admin operations, school setup, configuration, institute branding, module permissions, system settings.

⬇

📝 Learning & AI Layer

📝 content-service (LMS)

Stores lessons, notes, PDFs, videos, assignments, quizzes, submissions, content versioning, and publishing workflow. Acts as the LMS core.

🤖 ai-service

AI-powered quiz generation, lesson creation, explanations, summaries, RAG-based answers, embeddings, vector search, and per-school AI credit/token control.

⬇
📢 communication-service

Handles email, SMS, WhatsApp notifications, announcements, reminders, parent-teacher chats & alert routing.

🧰 Tech Stack & Tools

Backend

  • ✔ Spring Boot (Java 17+)
  • ✔ Spring Security, Spring Data, Spring Cloud
  • ✔ Spring AI for LLM integration
  • ✔ Microservices architecture
  • ✔ JWT & OAuth2

Databases

  • ✔ MySQL → structured transactional data
  • ✔ MongoDB → lesson content, AI logs, LMS data
  • ✔ Redis → caching, sessions
  • ✔ Elasticsearch → keyword search
  • ✔ Vector DB (Milvus/Weaviate) → RAG search
  • ✔ S3/MinIO → file storage

AI Stack

  • ✔ OpenAI / Claude (cloud LLMs)
  • ✔ Local models: Llama3 / Mistral (GPU server)
  • ✔ Langchain4j (optional)
  • ✔ Embeddings + RAG pipeline
  • ✔ Prompt templates & caching

DevOps & Tools

  • ✔ Docker + Compose
  • ✔ Kubernetes (phase-2)
  • ✔ Nginx API Gateway (or Spring Cloud Gateway)
  • ✔ GitHub Actions / Jenkins CI/CD
  • ✔ Grafana + Prometheus monitoring
