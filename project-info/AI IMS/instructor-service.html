Mapping & Implementation Notes

  • instructors.user_id → linked to auth.users.id (single source of truth for authentication).
  • instructor_subjects.subject_id → references academic.subjects.id in Academic Service.
  • Store large files (instructor_documents.file_url) in S3/MinIO and keep only the path in DB.
  • Index specialization and frequently queried FK columns for faster lookups.
  • Use UTC for all timestamps (join_date, uploaded_at) and add audit fields (created_by, updated_by) if required.
  • Consider soft-delete (is_active or deleted_at) for instructors instead of hard deletes to preserve historical data.
  • For syncing with HR/Payroll (finance-service), expose API endpoints to fetch instructor basic profile and remuneration attributes securely.
