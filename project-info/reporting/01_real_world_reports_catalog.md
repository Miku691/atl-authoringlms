# IMS Real-World Reports Catalog

> Deep research on what reports matter in a real-world Institute Management System.  
> Covers schools, colleges, and coaching centers — mapped to our IMS domain.

---

## 1. Academic Reports

### 1.1 Student Performance Reports
| Report | Description | Format | Audience |
|--------|-------------|--------|----------|
| Individual Report Card | Grades per subject per student per exam | PDF | Student / Parent |
| Class Performance Summary | Average marks per subject across a class | PDF / Excel | Admin / Teacher |
| Toppers List | Rank-wise student performance in an offering | PDF | Admin / Teacher |
| Subject-Wise Analysis | Pass/fail rate, average, highest, lowest per subject | PDF / Excel | Admin |
| Comparative Progress Report | Student performance across multiple sessions | PDF / Excel | Admin / Teacher |
| Examination Result Sheet | Full bulk result for an offering | Excel / PDF | Admin |
| Grade Distribution Report | Distribution of A/B/C/D/F grades | PDF / Chart | Admin |

### 1.2 Attendance Reports
| Report | Description | Format | Audience |
|--------|-------------|--------|----------|
| Daily Attendance Register | Who was present/absent on a given day | PDF / Excel | Teacher / Admin |
| Monthly Attendance Summary | % attendance per student per month | PDF / Excel | Admin / Parent |
| Student Attendance Report | Full attendance history for a student | PDF | Admin / Parent |
| Class Attendance Overview | Average attendance across all students per class | Excel | Admin |
| Attendance Defaulter List | Students below threshold (e.g., <75%) | PDF / Excel | Admin / Teacher |
| Subject-Wise Attendance | Attendance per subject for a student | PDF / Excel | Student / Admin |
| Staff / Instructor Attendance | Teacher attendance by day/month | PDF / Excel | Admin |
| Date-Range Attendance Export | Bulk attendance for any date range | Excel / CSV | Admin |

### 1.3 Assignment & Assessment Reports
| Report | Description | Format | Audience |
|--------|-------------|--------|----------|
| Assignment Submission Status | Who submitted / pending / late | PDF / Excel | Teacher |
| Assignment Score Sheet | Marks per student per assignment | Excel | Teacher / Admin |
| Assessment Completion Report | How many assessments completed per offering | PDF | Admin |

### 1.4 Academic Structure Reports
| Report | Description | Format | Audience |
|--------|-------------|--------|----------|
| Timetable Report | Full class timetable for a session | PDF | Student / Teacher |
| Syllabus Coverage Report | % of syllabus covered per subject | PDF | Admin / Teacher |
| Offering Overview | Summary of all active offerings for a session | PDF / Excel | Admin |
| Subject Master List | All subjects with credits, codes | Excel / PDF | Admin |

## 5. Advanced / Analytics Reports

> These are "enterprise-grade" reports for management decision-making.

### 5.1 Predictive & AI-Assisted Reports (Phase 2)
| Report | Description | Value |
|--------|-------------|-------|
| At-Risk Student Report | Students likely to fail based on attendance + grades | Early intervention |
| Enrollment Forecast | Predicted enrollment for next session | Planning |
| Revenue Forecast | Projected fee collection based on enrollment | Budget planning |
| AI Syllabus Coverage Advisor | Alerts when a subject is falling behind | Compliance |

### 5.2 Institutional KPI Dashboard
| KPI | Metric |
|-----|--------|
| Total Active Students | Count by gender, program |
| Attendance Rate (Institute-Wide) | Average across all classes |
| Fee Collection Rate | % collected vs total demand |
| Enrollment Growth | YoY new admissions |
| Dropout Rate | Students who left vs enrolled |
| Subject Pass Rate | % pass per subject |
| Faculty Load | Avg. subjects per instructor |
| Budget Utilization | Spent vs allocated |

### 5.3 Comparative / Trend Reports
| Report | Description |
|--------|-------------|
| Year-on-Year Enrollment Trend | Enrollment growth graph |
| Month-wise Fee Collection Trend | Revenue pattern through the year |
| Academic Performance Trend | Grade trends across sessions |
| Attendance Trend | Monthly attendance rate over sessions |

### 5.4 Compliance & Regulatory Reports
| Report | Description | Typical Use |
|--------|-------------|-------------|
| TC (Transfer Certificate) | Official leaving certificate | Government compliance |
| Bonafide Certificate | Proof of enrollment | Banks, scholarships |
| Student Strength Register | Total students per class | Govt. inspection |
| Scholarship Report | Students receiving scholarships | Govt. audit |

## 6. Export Formats Summary

| Format | Best For |
|--------|---------|
| **PDF** | Official documents, receipts, certificates, report cards |
| **Excel (XLSX)** | Admin bulk data, financial analysis, large registers |
| **CSV** | Bulk data exchange with other systems, simple exports |
| **In-App Dashboard** | KPI visualization, live charts, management view |
